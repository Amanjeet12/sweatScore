# AI Coach release decisions needed

These are product decisions, not inferred implementation rules. The original daily and meal prompts and examples remain unchanged. Record an explicit client answer and acceptance examples for each item before treating the related journey as approved.

| Decision                            | Precise question                                                                                                                                                                                                                                                                       | Current safe handling                                                                                                                                                                                                                                                                                                            |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| High-step recovery                  | What numeric threshold makes three consecutive days “well above average,” and which days count when sensor coverage is incomplete?                                                                                                                                                     | The validator does not invent a threshold; ambiguous plans fail validation/retry.                                                                                                                                                                                                                                                |
| Combined readiness                  | Which condition takes priority when a full-session answer conflicts with poor sleep, energy, mood, or recovery, and when completed-workout recovery combines with soreness?                                                                                                            | Pain/rest exclusions and compatible upper/lower soreness constraints remain enforced; undefined combinations are not silently ranked. A light-session answer with soreness is already covered by two explicit prompt rules: 10 minutes and the opposite-body strength split, so it no longer needs a separate priority decision. |
| Meal examples and bowls             | Should the jollof/plantain stacked-carb example's “Nearly there” override the general “Room to improve” rule? How much pounded yam is acceptable on a training day? For layered bowls, which visible portion estimate and verdict should govern when starch occupies most of the bowl? | The supplied prompt and six examples are preserved; contradictory examples are not rewritten.                                                                                                                                                                                                                                    |
| Scans, retakes and abandoned drafts | Do dispatched failed, unclear, non-meal and retaken images each consume one of three daily scans? May an abandoned draft be resumed or shared tomorrow?                                                                                                                                | Current provisional policy counts each provider-dispatched scan, not an undispatched reservation; retakes do not refund dispatched calls. A valid successful meal analysis is required before sharing.                                                                                                                           |
| Expired access and renewal          | What historical Today/Progress/community content remains visible after expiry, and where should a verified renewal purchase begin without an unrelated in-app upsell? Are trial/reminder offers actually configured?                                                                   | Access-limited Today and server-verified Restore are provisional; no unsupported trial/reminder is promised.                                                                                                                                                                                                                     |
| Changed-day checkout                | What message should appear when checkout resumes after the member-local day changes, and how should timezone/DST changes be explained?                                                                                                                                                 | Yesterday's plan remains history; fresh daily answers are required for the new day.                                                                                                                                                                                                                                              |
| Rest-day voluntary workout          | Can a member voluntarily complete a workout on a rest/pain plan and earn the Workout slot, or is that slot unavailable?                                                                                                                                                                | No mandatory Workout assignment is created for rest/pain.                                                                                                                                                                                                                                                                        |
| Delayed uploads and reversals       | Which day owns a proof uploaded after midnight? Can a deleted post or reversed completion ever reopen a consumed reward slot?                                                                                                                                                          | Capture pins its original day/context; a consumed slot is never silently reopened or awarded again.                                                                                                                                                                                                                              |
| Ambiguous legacy categories         | Which exact old category IDs (Jump Rope, Core, Strength, Dance, Daily Streak) map to Workout or another stable slot, and what proof/points conditions apply? How are incomplete device uploads mapped when capture context is absent?                                                  | No custom category is mapped automatically; hydration is never Workout proof. Historical points remain unchanged.                                                                                                                                                                                                                |

This sheet does not authorise scheduler retirement. The development gate also requires sandbox billing, device journeys, a current Today screenshot, full upload/queue inspection, and a repeatable approved migration ledger.
